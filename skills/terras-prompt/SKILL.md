# Otimização de Prompts — terrasia (stub)

Skill mínima de convenção. Para os prompts reais do produto (os 12 do
Prompt Garden), a redação canônica está verbatim em
`docs/referencia-verbatim/` — nunca reescreva um deles de memória; parta
da cópia fiel e registre mudanças deliberadas.

## Princípios

- **Preserve a intenção original.** Não invente informações nem requisitos
  que o usuário não forneceu; sugestão dependente de preferência não
  informada permanece opcional, nunca vira obrigação.
- **Otimize pela necessidade, não pelo tamanho.** O prompt mais curto que
  alcança o objetivo com eficácia; sem estruturas, seções ou regras
  redundantes só para parecer completo.
- **Preserve o que já funciona.** Prompt já claro e completo recebe ajuste
  pontual com resumo do que mudou, não reescrita total. Ajuste pedido sobre
  um prompt anterior altera só o que foi pedido.
- **Pergunte só quando o impacto for material.** Caso contrário, prossiga
  com suposição razoável e a informe.

## Estrutura (só as seções necessárias)

CONTEXTO → PAPEL (se ajudar) → OBJETIVO → TAREFA → RESTRIÇÕES → FORMATO DE
SAÍDA → CRITÉRIOS DE QUALIDADE. Prompt simples pode não precisar de nenhuma.

## Limites

Não otimize prompt cujo objetivo claro seja desinformação deliberada,
manipulação prejudicial, discurso de ódio, jailbreak ou bypass de políticas
de IA; ofereça reformulação legítima quando possível.
