# Otimização de prompts por princípios

## Descrição

Use ao criar, revisar, avaliar ou ajustar um PROMPT (o texto de instrução dado a uma IA), não para executar a tarefa que ele descreve. A versão neutra: preserva a intenção original, otimiza pela necessidade (não pelo tamanho) e nunca recria de memória um prompt canônico do projeto — parte-se da cópia fiel e registram-se mudanças deliberadas.

## Quando usar

- Pedido de otimizar, reescrever, avaliar ou encurtar um prompt.
- Montar prompt novo a partir de uma ideia solta.
- Não usar para executar a tarefa que o prompt descreve.

## Princípios

- **Preserve a intenção original.** Não invente informações nem requisitos; sugestão dependente de preferência não informada permanece opcional, nunca vira obrigação.
- **Otimize pela necessidade, não pelo tamanho.** O prompt mais curto que alcança o objetivo com eficácia; sem seções ou regras redundantes só para parecer completo.
- **Preserve o que já funciona.** Prompt já claro e completo recebe ajuste pontual com resumo do que mudou, não reescrita total. Ajuste pedido sobre prompt anterior altera só o que foi pedido.
- **Pergunte só quando o impacto for material.** Caso contrário, prossiga com suposição razoável e a informe.

## Estrutura (só as seções necessárias)

`CONTEXTO → PAPEL` (se ajudar) `→ OBJETIVO → TAREFA → RESTRIÇÕES → FORMATO DE SAÍDA → CRITÉRIOS DE QUALIDADE`.

Prompt simples pode não precisar de nenhuma seção — estrutura é meio, não meta.

## Casos comuns

| Pedido | O que fazer |
|---|---|
| "encurta esse prompt" | Remover redundância e seções não essenciais, preservando toda afirmação que carrega informação; declarar o que saiu |
| "avalia esse prompt" | Verificar contra os princípios acima e apontar o que falta ou sobra, com a correção sugerida |
| "monta um prompt pra X" | Estrutura mínima: objetivo, contexto que o executor precisa, restrições relevantes, formato de saída |
| "adapta pra outra IA" | Ajustar à plataforma sem mudar intenção nem requisitos |

## Limites

Não otimize prompt cujo objetivo claro seja desinformação deliberada, manipulação prejudicial, discurso de ódio, jailbreak ou bypass de políticas de IA; ofereça reformulação legítima quando possível.

## Critério de qualidade

O resultado preserva toda informação do original (nada inventado, nada perdido), ficou mais curto ou mais claro conforme o pedido, e o resumo diz exatamente o que mudou — para o usuário poder reverter qualquer decisão.
